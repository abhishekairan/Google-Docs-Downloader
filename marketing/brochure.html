Tab Downloader for Google Docs

Google Docs lets you split a document into tabs — but download only gives you "current tab" or "everything". This extension gives you a checklist.

Tick the tabs you need, choose one or more formats, click once. Every tab becomes its own file with a sensible name.

Get it on the Chrome Web Store →
Works in Chrome, Brave, Edge and other Chromium browsers. No account, no OAuth, no servers — it uses the Google session you already have. Not affiliated with Google.

Why people install it

🗂️ Pick exactly the tabs you need
Every tab and nested subtab in a checklist, with All / None / Current shortcuts.
📄 Eight formats, several at once
PDF, Word, OpenDocument, RTF, plain text, Markdown, HTML, EPUB — select more than one and get each tab in each format.
🏷️ Sensible file names
"Document – Tab.pdf", numbered, or tab-only. Subtabs can carry their parent's name. Save into a folder or bundle into one .zip.
⚡ Fast on big documents
Markdown and text of a 30-tab document arrive in a second. PDF/Word are paced to Google's export limit with automatic retry and an ETA.
🔒 Private by design
The only server it talks to is docs.google.com. No analytics, no telemetry, no remote code. Preferences stay in your browser.
🛋️ Fire and forget
Close the popup — downloads keep running in the background. Reopen it any time to see progress or cancel.

How it works

1 Open a Google Doc
Any document with tabs. Click the extension icon.
2 Tick tabs, pick formats
Preview the file names before you download.
3 Download
Files land in Downloads, one per tab (or one zip).
